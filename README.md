## 01 / About me

I'm **Carlos Gabriel Ribeiro**, an **Applied Mathematics and Computational Mathematics graduate from the University of Campinas (UNICAMP)**, interested in transforming mathematical ideas into reliable computational systems.

My work and studies connect **machine learning, operations research, scientific computing, and software engineering** — from designing optimization models and experimenting with neural networks to implementing practical, reproducible solutions.

- **I work with:** mathematical modeling, optimization, machine learning, scientific Python.
- **I'm exploring:** intelligent agents, hypercomplex neural networks, neuro-fuzzy systems, and scientific machine learning.
- **What drives me:** understanding *why* algorithms work and using that understanding to build better systems.
